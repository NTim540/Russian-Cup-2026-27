Общая таблица

?Как распределяются места при равенстве очков? Если команды с одинаковым количеством очков играли в одной группе в любом из прошедших туров, учитываются результаты личных встреч: очки в личных встречах → разница шайб в личных встречах → общая разница шайб → количество побед → победы в основное время → заброшенные шайбы. Если команды играли в разных группах и не встречались между собой, применяются: победы в основное время → общая разница шайб → заброшенные шайбы. Если после применения одного из критериев несколько команд по-прежнему равны, для них сравнение начинается заново. Основание: статья 17 Регламента Кубка России U16.
Групповой этап

Группы

?Внутри одной группы за выбранный тур: очки в личных встречах → разница шайб в личных встречах → общая разница шайб → все победы → победы в основное время → заброшенные шайбы. После разделения команд оставшиеся равные команды сравниваются заново с пункта 1; личные встречи пересчитываются только между оставшимися командами. При полном равенстве всех критериев преимущество не определено, порядок строк технический.

Как устроен турнир

На главной — только самое важное. Полную версию регламента позже вынесем на отдельную страницу.
01

Система очков

Победа, поражение в овертайме или по буллитам и поражение в основное время учитываются по настройкам турнира.

02

Определение мест

При равенстве очков применяются последовательные критерии. Подробности доступны через знак «?» рядом с таблицами.

03

Формат этапа

В каждом туре команды распределены по четырём группам. Во втором туре предусмотрены стыковые матчи, результаты которых учитываются в общей таблице, но не в таблицах групп.
